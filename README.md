# Kantin JTI (PeBeeL)

Aplikasi pemesanan makanan kantin JTI. Proyek Project Based Learning.

**Teknologi:** HTML, CSS, JavaScript, PHP Native, PostgreSQL.

## Struktur folder

```
kantin-jti/
├── index.html      halaman katalog pelanggan (nanti jadi index.php)
├── css/style.css   semua gaya halaman
├── js/             JavaScript
├── images/         foto menu
└── README.md
```

## Cara melihat hasilnya

Buka `index.html` di browser (klik dua kali, atau pakai Live Server di VS Code).
